# Phase 3 evidence

Run `godot --headless --path . --script res://tests/phase3_checks.gd` from this project directory to regenerate `phase3-checks.json`.

This evidence was produced from the current Contract 1.3 code, which includes later Phase 4 changes. It is a focused regression of the Phase 3 fuel, relight/refuel, capacity, score, lantern-out, and dawn rules; it is not a historical Phase 3 build or a substitute for the missing `phase-3` Git tag.
