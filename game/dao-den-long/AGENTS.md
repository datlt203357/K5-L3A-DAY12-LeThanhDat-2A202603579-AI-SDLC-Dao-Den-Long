# Agent instructions

- Keep gameplay rules in `scripts/game_sim.gd`; rendering and menus belong in `scripts/main.gd`.
- Headless and interactive play must use the same `GameSim` logic.
- Preserve `game.contract.json` values and output fields exactly; update tests and notes when requirements change.
- Run `godot --headless --path . --check-only --script res://scripts/game_sim.gd` and `godot --headless --path . --script res://tests/contract_checks.gd` after simulation changes.
- Run the contract runner as `godot --headless --path . --script res://scripts/headless.gd -- --seed 42 --night 1 --ticks 600 --out out.jsonl`.
- Do not claim a feature or evidence is complete until its command/output has been inspected. Keep proof output generated by the code, never hand-edit results.
- Do not commit Godot binaries, `.godot/`, credentials, or local save data.
