# Changelog

## Phase 1 — PRD-0 / Contract 1.0

- Initial playable night, fixed-tick simulation and JSONL headless runner.

## Phase 2 — Ticket-02 / Contract 1.1

- Three island nights, normalized movement, dash, charms, drifters, pause and expanded contract output.

## Phase 3 — Ticket-03 / Contract 1.2

- Breaking changes: lamps can run out of fuel; they can be relit/refueled; victory moves from all-lamps-lit to surviving dawn with the required lamp ratio; night durations and score formula change; player carry capacity grows after successful lights; shades can drain low-fuel lamps.
- Adds stored colorblind palette preference.

## Phase 4 — Ticket-04 / Contract 1.3

- Adds benchmark, soak runner, local leaderboard export, key rebinding and accessibility settings.
